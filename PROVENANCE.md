# PROVENANCE

agnostic is MIT, written to this repo's own code standards. Ideas came from
open-source projects such as Orca and Agent Deck (MIT) and Superset (ELv2);
the few files adapted from MIT code say so in their header.

Fonts are SIL OFL 1.1, licence beside each family under
`packages/ui/src/styles/fonts/`. The catalog is transcribed by hand from public
leaderboards and vendor pages; its `sources` table says where each number came
from, and only aggregate scores are redistributed.
